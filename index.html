About

Twelve years spent making the same argument in eight different rooms.

Iris Marek trained as a printmaker, then spent a decade moving between fashion ateliers, branding studios, and the odd 3D render farm — never quite settling, on purpose. The work here shares one belief: craft and technology aren't opposing forces, they're doors between the same building.

Recent work leans into AI-assisted drafting as a starting point rather than an ending one — a way to draft faster so more time goes to the part only a hand can do.

I don't think a good idea cares which software made it. It cares whether you were paying attention.
